| Feature                       | pnpm                                                                                                             | yarn (Berry/v4)                                                                                               | npm                                                                                                                                      |
|-------------------------------|------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------|
| Minimum Node.js version       | v18.12+                                                                                                          | v18.0+                                                                                                        | Currently supported LTS versions                                                                                                         |
| Uses Lock file                | Yes                                                                                                              | Yes                                                                                                           | Yes                                                                                                                                      |
| Install Strategy              | Content-addressable store with hard links and symlinks.                                                          | Plug'n'Play (PnP) by default (uses a .pnp.cjs file and a zip cache instead of node_modules).                  | Copies dependencies into a flat node_modules folder for every project.                                                                   |
| Disk Space Usage              | Very Low. A single global copy of a package is shared across all projects.                                       | Low. Compresses packages into zip archives when using PnP.                                                    | High. Duplicates packages entirely for each project.                                                                                     |
| Install Speed                 | Fastest. Often 2-3x faster than npm during cold installs.                                                        | Fast. Very fast in PnP mode, but can be slower if configured back to standard node_modules mode.              | Slowest. Consistently trails behind Yarn and pnpm in benchmarks.                                                                         |
| Phantom Dependency Protection | Yes. Its strict, isolated folder structure prevents you from importing packages you didn't explicitly install.   | Yes. PnP strictly rejects access to unlisted dependencies.                                                    | No. The flat structure allows packages to accidentally import undeclared dependencies.                                                   |
| Zero-Install Support          | Not natively supported.                                                                                          | Yes. Supported out of the box by committing the .yarn/cache to Git.                                           | Not natively supported.                                                                                                                  |
| Best Used For                 | Teams wanting maximum speed, disk efficiency, and strict dependency rules without fighting compatibility issues. | Advanced monorepos and teams willing to configure editor SDKs to achieve zero-installs and strict boundaries. | Small projects or teams requiring maximum "out-of-the-box" compatibility with older legacy tools that expect a flat node_modules folder. |
