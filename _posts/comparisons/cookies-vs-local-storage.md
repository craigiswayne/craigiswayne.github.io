| Feature                            | Local Storage                                                                                                                                        | Cookies                                                                                                                                                                                                                        |
|------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Capacity                           | ~5MB to 10MB per origin                                                                                                                              | ~4KB per cookie (maximum)                                                                                                                                                                                                      |
| Lifetime                           | Persists indefinitely until explicitly cleared via code or user action                                                                               | Can be session-based or set with an explicit expiration date (Expires/Max-Age)                                                                                                                                                 |
| Server Communication               | Strictly client-side; never sent in HTTP headers  saving network bandwidth                                                                           | Automatically attached and sent with every single HTTP request to the server                                                                                                                                                   |
| Accessibility                      | Synchronous API accessible exclusively via client-side JavaScript                                                                                    | Accessible by client-side JavaScript (unless restricted) and readable by the backend server                                                                                                                                    |
| Security                           | Highly vulnerable to XSS (Cross-Site Scripting) attacks since any injected script can read it                                                        | Can be heavily protected using HttpOnly (blocks JS access, Secure (HTTPS only) and SameSite flags                                                                                                                              |
| Access by Other Sites / Subdomains | Strictly bound by the Same-Origin Policy; completely isolated. Even subdomains (a.example.com and b.example.com) cannot access each other's storage. | Bound by origin rules for JavaScript, but can be explicitly shared across subdomains (e.g. setting Domain=.example.com). Unrelated external sites cannot read them and SameSite attributes control cross-site request sharing. |
